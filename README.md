# Калькулятор (Android, Java)

Учебный проект, переработанный во вторую версию: появилось полноценное
вычислительное ядро с приоритетами операций, скобками, корнем и процентами,
живой предпросмотр результата, память (M), история и три режима темы.

## Что нового

- **Новое ядро вычислений** (`calc/ExpressionEvaluator`): разбор выражения
  по алгоритму сортировочной станции, корректный приоритет `× ÷` над `+ −`,
  унарный минус, скобки, `√`, `%`. Расчёты идут в `BigDecimal` — больше нет
  `0.30000000000000004` и «хвостов» из `double`.
- **Логика ввода вынесена из Activity** (`calc/CalculatorSession`): правила
  запятой, повторных операторов, `±`, `⌫`, `C`, автозакрытие скобок.
  Покрыта unit-тестами (24 теста, `./gradlew test`).
- **Живой предпросмотр**: под табло показывается `= результат` ещё до нажатия «=».
- **Память калькулятора**: `M` — MR / M+ / M− / MC, долгое нажатие — сохранить.
- **История вычислений**: последние 50 операций, нажатие на запись вставляет результат.
- **Новые клавиши**: `(`, `)`, `√`, `±`; процент считается «как на настоящем
  калькуляторе»: `200+10% = 220`.
- **Темы**: системная / светлая / тёмная (трёхпозиционный переключатель),
  цвета клавиатуры заданы атрибутами темы.
- **Ошибки** больше не «ломают» калькулятор: деление на ноль, корень из
  отрицательного и переполнение показываются сообщением, ввод остаётся на экране.
- Настройки: звук клавиш, вибрация; состояние переживает поворот экрана
  и перезапуск приложения.

## Структура

```
app/src/main/java/ru/geekbrains/calculator/
├── CalcApp.java              — Application, применяет режим темы
├── CalcPreferences.java      — настройки (тема, память, звук, вибрация)
├── MainActivity.java         — экран калькулятора (только UI-склейка)
├── Settings.java             — экран настроек
├── calc/                     — чистая Java без Android, покрыта тестами
│   ├── ExpressionEvaluator.java  — разбор и вычисление выражений
│   ├── CalculatorSession.java    — состояние и правила ввода
│   ├── NumberFormatter.java      — форматирование чисел
│   ├── HistoryStore.java         — история вычислений
│   ├── HistoryEntry.java
│   ├── CalcError.java / CalcException.java
└── ui/CalcKeypad.java        — единый обработчик нажатий клавиатуры
```

## Сборка и тесты

```bash
./gradlew assembleDebug   # сборка APK
./gradlew test            # unit-тесты вычислителя и логики ввода
```

Требования: JDK 17, Android SDK 36 (compileSdk 36, minSdk 24).
